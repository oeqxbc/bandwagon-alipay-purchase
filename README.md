## 买之前先确认三件事

搬瓦工的套餐是"固定配置套餐"，不是你想要多少就调多少，所以下单前先对号入座。

**第一，内存别压太紧。** 官方建议配置时内存至少留 512MB 余量，比如你打算跑的服务实际占 500MB，就选 1GB 以上的套餐，不然容易触发 OOM。

**第二，流量按月算，但封顶限速。** 每个套餐标注的流量是每月额度，超出后不是按量计费，而是网速降到 1Mbps，下个月自动恢复。线路方面，CN2 GIA-E 和香港、东京的 CN2 GIA 套餐对大陆访问最友好，普通 KVM 套餐走的是普通线路，价格便宜但高峰期表现一般。

**第三，退款有条件。** 账户注册 30 天内可以申请退款，但要求：账户下 VPS 少于 3 台、累计支付金额低于 100 美元、没有发起过支付争议、分配的 IP 没有被封。满足条件是全额退款，用支付宝付的会原路退回。超过 30 天就没得退了，这点买之前心里要有数。

## 支付宝购买常见问题

**扣款金额怎么和标价对不上？** 标价是美元，支付宝实际扣人民币，按付款当天的汇率换算，所以每次看到的金额会有一点浮动，属于正常现象。

**付款后订单显示 Unpaid 怎么办？** 有几种可能：付款时跳回主域名后浏览器没完成回传、付款后太快关闭了页面，或者支付状态同步延迟。先等 5~10 分钟刷新订单页面，多数会自动变更为已付款。真没反应就开着支付宝扣款凭证提交工单，客服能核对到账记录后手动开通。

**续费还能用支付宝吗？** 可以。续费账单生成后进入付款页面，同样有 Alipay 选项，和首次购买共用支付通道。

**发票和账单去哪看？** 登录 KiwiVM 或客户后台，在 Billing 区域可以看到所有历史账单和支付记录，需要报销凭证的话账单页可以打印。

**买错了机房能换吗？** 能。CN2 GIA-E 等套餐本身支持在面板里自助切换机房，数据会随迁移带走，不额外收费。普通 KVM 套餐的可选机房范围小一些，下单前看清楚套餐说明。
